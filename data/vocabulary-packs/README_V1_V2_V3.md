# Vocabulary V1 / V2 / V3 — Professional Focus

## Recommended import order
1. `V1_professional_focus_2500.json` — complete V1, includes the previous 860-item base and expands to 2,500 items.
2. `V2_additions_2500.json` — import after V1; adds 2,500 new items, cumulative total 5,000.
3. `V3_additions_2500.json` — import after V2; adds 2,500 new items, cumulative total 7,500.

If installing from scratch at a later stage, you can instead use `V2_cumulative_5000.json` or `V3_cumulative_7500.json`. Do not import both a cumulative pack and its corresponding additions unless you intentionally want the merge logic to deduplicate them.

## Focus
- Business / Finance / Accounting remain the dominant professional coverage.
- Daily is used for advanced general English needed for real life, university, workplace and spoken communication; very basic A1 vocabulary was not deliberately bulk-added.
- Specialist additions are primarily selected from ECDICT entries explicitly marked with the economic/business sense `[经]`.
- Finance and Accounting are further classified from the selected professional sense; remaining professional items go to Business.

## Priority
- Existing base items: unchanged.
- V1 additions: priority 8.
- V2 additions: priority 6.
- V3 additions: priority 4.

## Pronunciation
No UK/US IPA or audio URL is fabricated. Missing pronunciation data should use the application's existing en-GB/en-US TTS fallback.

## Bulk-entry policy
Bulk dictionary additions intentionally keep `examples` and `collocations` empty unless they already existed in the original 860-item base. This avoids mass-generating unreliable example sentences. These fields can be enriched later.

## Source
The large dictionary expansion uses ECDICT (MIT-licensed English-Chinese dictionary data) as the lexical source.
