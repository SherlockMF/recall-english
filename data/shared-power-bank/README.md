# 共享充电宝商业化词库

42 个工作表达，覆盖商户合作、点位拓展、租借流程、设备运营、收入分成及结算。中文仅对应本文件中的特定义项，定义和双语例句为本项目编写。charging station 在这里指充电宝租借站点，区别于电动车充电站；site acquisition 在这里指业务点位拓展，区别于土地收购。

- `vocabulary.tsv`：七列文本格式，可整表复制到添加页；不需要更改列顺序。
- `shared-power-bank.vocabulary.json`：完整词库包，包含定义、双语例句与工作场景。在设置中选择「导入词库」进行合并，支持离线使用。

也可直接打开「添加」，点击「加入 42 个工作表达」，无需另行查询词典或准备文件。

JSON 中使用稳定 ID 与独立义项标识，可重复导入同一文件。新词加入优先学习，按每日固定额度推进；重复导入保留已有进度、已会及编辑。没有把工作短语等级冒充为经测评的 CEFR 义项等级。

术语选择参考行业官方公开页面：[Brick 合作介绍](https://www.brick.tech/en-it/partnership)、[怪兽充电公开年报](https://www.sec.gov/Archives/edgar/data/1834253/000141057825000928/em-20241231x20f.htm)。仅核对 powerbank rental、venue、network partner、rental revenue 等行业表达；本词库不沿用任何公司的价格、佣金比例或收益承诺。工作例句中的合同与财务词语用于语言练习。
