来源为有道 `jsonapi` / `jsonapi_s`，中文义项为学习单位；扩展释义中的例句按对应义项保存。旧接口部分查询会返回不同词头，因此异常结果用 `jsonapi` 复查；不匹配的结果不写入。支持旧版嵌套释义，并逐义项过滤人名，避免丢失相机等正常释义。

`report.json` 保留每个未解决表达的具体原因；未收录主要为完整问句和专业组合短语。它们已有的内容继续保留。不同词头的变体未自动合并；不人为制造多义，不宣称来源包含全部历史或专门用法。

`additionalExpressions.json` 是现有本地工作词库中不同于种子库的表达清单；它只扩展查询范围，浏览器不会因此恢复已删除词条或创建不在本地的词条。

增量包：`public/data/bundledDictionarySenses.json`。运行 `npm run seed:senses` 可续跑构建；使用 `-- --retry-unresolved` 可重新查询未解决记录。原词、用户编辑、分类和学习记录保留；新增义项默认暂停。对多个标签页的启动合并，读取、匹配、写入和版本更新均在同一个 IndexedDB 事务完成。

初次联调发现跨标签页竞态并已修复；本机本次导入产生的未学习重复项采用限定旧版本和时间范围的修复，编辑、已会、优先学习和有作答记录的词条不会删除。清理前的完整备份另存于本机 `.superpowers/validation/backups/full-senses-before-repair.json`，不进入 Git。

## 2026-10-13 英语语境补齐

原有 8,327 个来源义项没有英语定义、例句或搭配。本次经来源复核后补齐 2,386 个，剩余 5,941 个未找到可以明确对应的英语资料；缺口逐项记录在 `context-report.json`。不把其他义项的例句按词性随意分配，也不生成冒充词典来源的资料。

补齐优先复用现有种子库中可唯一匹配中文义项的资料，再使用来源词典中可明确对应的 Collins 双语定义、双语例句或唯一 WordNet 定义。英语栏目必须明确标注 WordNet 来源，不使用 Wikipedia 的同名影视或百科条目。只补空白资料，保留原中文学习单位及已有内容；错误的自动来源定义仅按完整文字精确匹配纠正，用户编辑及学习记录保留。

运行 `npm run seed:contexts` 可续跑语境补齐，`-- --retry-missing` 可重新查询仍有缺口的表达；完成后运行 `npm run seed:senses` 生成增量包和版本。缓存记录包含查询结果及检查时间，失败不会替换已有来源义项。

若需从原始来源重新审查本次自动补齐资料，可使用 `-- --rebuild-contexts`；必须保留包含全部原始查询结果的 journal，否则脚本拒绝重建。

有道义项标识改为词性、中文来源释义及同释义序号，不再随英语定义或例句补充而变化。加载时安全匹配旧标识，保留原词条 ID、用户编辑和独立学习记录。手动补全与启动补全均采用原子事务；补全资源加载失败时仍可使用本地词库，并可点击重试。
