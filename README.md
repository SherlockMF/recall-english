# Recall English

本地优先的主动回忆英语学习网页：不靠选择题，用「想起再说出」巩固表达。

面向马来西亚大学生活、商业沟通，以及金融 / 会计专业场景。学习进度保存在当前浏览器（IndexedDB），可选 DeepSeek 辅助判分与补全。

## 功能概览

- **三条学习轨道**：日常生活 · 商业英语 · 金融会计（词库内再分 Daily / Business / Finance / Accounting）
- **主动回忆**：English → 中文、中文/场景 → English、真实使用；正式训练不提供选项
- **每日共享预算**：默认 15 分钟、最多 5 个新表达；时长可设 5—120 分钟，新表达可设 0—100 个（0 表示只复习）。回忆与应用共用时间，可分多次完成
- **FSRS 复习**：默认按约 90% 目标保持率安排间隔；这是排程目标，不代表已达到的掌握程度
- **可解释的学习证据**：理解意思、主动表达、延迟保持与场景应用分别记录；词条浮窗显示学习摘要，展开「学习依据与最近记录」可查看缺失条件和最近五条证据
- **内置词库**：**7497** 个义项（手写 240 + bundled 7257；V5.3 审计修复、不扩词）。seedContentRevision 变更时按 Word.id 刷新未编辑的种子正文；个人编辑、暂停、优先级、已会与难度覆盖及 FSRS track 保留。旧记录没有正文编辑标记时，时间戳显示曾修改的内容会保守保留。
- **查词与发音**：Free Dictionary API + 有道词典代理；UK / US 音频优先，缺失时回退 Web Speech
- **多义项词库**：同一个英文表达归并为小卡片，桌面三列，左侧英文、右侧最多三个中文义项；中文可显示两行，窄卡片将词义移到英文下方，避免英文区域过窄导致断词。点击英文或词义打开独立浮窗，切换全部义项时同步定义、例句、学习情况和操作对象。训练、优先学习、已会、编辑及「补全词义」均在浮窗操作，补全后卡片不会因全部义项撑长。添加页展示来源返回的全部词义，可勾选多个义项训练；未勾选的新增义项保存为暂停状态。补全支持按需查词，项目另附全库查询生成的增量义项包，不承诺穷尽所有用法。缺中文的义项仅供查阅，编辑补充后可加入训练。旧内容、ID 和进度保留，重复补全不重置学习记录。
- **可选 AI**：设置页输入 DeepSeek API Key，点击「保存 DeepSeek Key」立即保存，无需保存其他设置；标题旁显示未配置、待保存或已保存，存储失败时显示需检查。支持语义判分、分层提示、词条补全、usage 题懒生成；开放造句需主动点击 AI 验证，每次提交最多请求一次。未请求或失败保留“待验证”（Key 仅存 `localStorage`，不进入备份；已保存不代表真实调用已验证）
- **口语陪练双模式**：「实时畅聊」边说边回应，麦克风音量条随真实输入变化，可随时暂停和继续；「语音消息」按住说话、松开发送、上滑取消，也可点击录制，每条语音可回听和展开文字。均使用千问北京地域 `qwen3.8-omni-flash-realtime`，应用不限制练习时长；共用场景、难度、最多 3 个词与课后 DeepSeek 表达建议，不影响 FSRS 与每日复习预算
- **导入导出**：词库合并导入、学习备份整库替换；可请求浏览器持久存储。可导入 pack **不含**顶层 `note`（说明在 `*.meta.json`）
- **灵活添加**：单条或批量支持纯英文，按需查询现有词典并保存返回的多个义项；批量还支持 Tab、CSV、竖线、中英文空格及可调整列顺序的表头。默认按每个义项的定义、中文判断分类，也可明确指定；已有义项的个人分类、已会及进度保留。添加页可展开并复制「添加格式说明与示例」，补全失败的输入保留供重试；有格式错误时整段文本及表头保留。分类识别为可编辑的规则推断，词典返回内容不保证穷尽所有用法。
- **共享充电宝工作词库**：添加页提供「加入 42 个工作表达」，包含商户合作、点位拓展、收入分成、设备运营及结算的明确义项和双语例句。新增义项进入优先学习，每日数量仍按设置推进；[格式与可导入文件](data/shared-power-bank/README.md)。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可。首次启动会把缺失的种子词写入 IndexedDB。

```bash
npm test                    # 单元 / 组件测试
npm run lint                # oxlint 静态检查
npm run build               # 生产构建
npm run share:check         # 构建、生成 ZIP、解压并启动分享包进行冒烟检查
npm run share:export        # 生成完整应用分享包，默认放在 Downloads
npm run vocabulary:export  # 导出当前 V5.3 种子及 trusted 词包
npm run seed:pack           # 从 trusted_v5_2 重建 public/data/bundledSeed*.json
npm run seed:quality        # 词库硬闸
npm run seed:validate-sense # 义项一致性（strict）
```

CI 在构建后运行 `npm run share:check -- --skip-build`。检查包含完整种子一致性、静态资源、语音运行时、凭证排除和无效 URL 后服务仍可访问。两个导出命令支持 `-- --output-dir <directory>`，不会覆盖同名 ZIP；Windows 使用 PowerShell，macOS/Linux 需要 `zip` 和 `unzip`。构建与导出需要项目开发依赖，分享包运行只需要 Node.js 22+。

2026-10-22 已复核 130 条义项提示，修正 93 个既有条目的义项、例句或搭配，内容修订升至 5.3.1；见[逐项复核及验证记录](docs/vocabulary-review-2026-10-22.md)。现行 `seed:pack` 全量重建会比已发布资产多出 100 个待去重复核的条目，本次没有纳入这些条目；完整重建前请先查阅记录中的生成器差异。

DeepSeek Key 按浏览器地址保存：`localhost` 与 `127.0.0.1`、不同端口的配置互相独立。换启动地址后显示未配置时，可先检查以前使用的地址；Key 不包含在备份中。

### 配置千问口语陪练

需要 Node.js 22+，以及阿里云百炼**北京地域**业务空间、API Key 和 `qwen3.8-omni-flash-realtime` 调用权限。

打开「学习设置 → 千问口语陪练」，输入北京地域的 API Key 和业务空间 ID，点击「保存口语配置」。配置立即用于下次连接，无需重启；「清除口语配置」会禁用后续语音连接。已建立的对话仍可继续到结束。

凭证保存在本机服务目录的 `.env.voice.local.json`，不保存在浏览器、不返回给页面、不进入学习备份或分享包。此文件及临时文件已由 `.env.*` 排除出 Git，并由 Vite 默认规则禁止静态访问。服务目录需可写。UI 配置优先于环境变量；清除会保存禁用状态，重启后也不会自动回退到旧环境变量。

仍支持原有环境变量配置：将 `.env.example` 复制为项目根目录的 `.env.local`，在本机填写以下变量，然后重新运行 `npm run dev` 或 `npm run preview`：

```dotenv
DASHSCOPE_API_KEY=<your-beijing-api-key>
DASHSCOPE_WORKSPACE_ID=<your-workspace-id>
```

不要添加 `VITE_` 前缀。真实 `.env.local` 已被 Git 忽略，不会进入分享包或学习备份。分享包可直接在设置中保存配置；使用环境变量时，将 `.env.local` 放在 `server.mjs` 同目录，运行 `node server.mjs`。源码可用 `node scripts/shareLocalServer.mjs` 服务构建后的 `dist`。

打开「口语」先选择模式，再选择场景类型、难度和可选词汇。「日常生活 / 商务沟通 / 金融会计」是类别，卡片中的内容只是示例；可在「场景说明」中简述地点、双方角色和想练的内容（最多 500 字），AI 按说明调整，不绑定咖啡店等固定剧情。「自定义」可自行指定话题、角色和背景，留空时自由聊天。各类别的说明及模式切换时的选择保留在当前口语页内，开始后需先结束练习才能修改。

仅支持 HTTPS 或 localhost 安全上下文；本地语音接口仅允许本机同源访问，不支持直接以局域网 IP 访问。

「实时畅聊」开始后允许麦克风，音频通过 WebRTC 发送到千问，字幕通过 `txt` DataChannel 接收。音量条显示本机麦克风实际采集的声音；「AI 正在听你说」来自服务端语音检测，两者分别显示，音量变化不代表识别已完成。静音或结束时归零。

「语音消息」先建立会话，录制时才申请麦克风。默认按住说话、松开发送、上滑至少 60 px 取消；也可改为点击开始/结束录音。单条 1—60 秒，60 秒自动结束并发送，正在取消时丢弃；取消不上传。录音通过本机服务的 WebSocket Manual 会话提交 PCM，AI 用语音条回复；点击回听、展开文字。录音期间禁止回放以避免录入已有语音。发送失败保留原条录音，手动重试沿用消息 ID；连接已结束时重试会明确建立新的练习会话，不自动重连。

应用不限制对话总时长，计时显示已练习时间。实时畅聊的「暂停对话」会停止当前 AI 回复、关闭麦克风、停止播放并保留连接与字幕；「继续对话」重新开启麦克风，沿用当前对话，暂停时间不计入练习时长，原有静音设置保持不变。切到后台或 120 秒无交流时自动暂停，返回后需手动继续；离开或刷新页面仍会结束连接。语音消息不因等待或超过 5 分钟结束，每条录音仍为 1—60 秒；切到后台或离开时结束会话并释放麦克风。百炼单次连接最长 120 分钟，达到上限或网络断开时需手动重新开始，见[官方使用限制](https://help.aliyun.com/zh/model-studio/realtime)。实时字幕与消息录音/转写/反馈只存页面内存，不写入 IndexedDB 或学习备份；消息模式结束后仍可回听，重新开始、切换模式、离开或刷新后清理。请先复制或下载文字。

课后主动点击生成反馈，将**已完成的个人发言转写**发送给已配置的 DeepSeek（最多 30,000 字符，超出时仅发送此前完整发言）。反馈只针对文字表达，不评估发音或证明掌握程度。AI 字幕来自生成，可能包含被打断时尚未听到的内容；字幕也可能识别错误。

费用按百炼实际用量计费。界面仅估算收到的语音模型 tokens，采用 2026-10-07 北京价格：文本输入/输出为 1.5/4.5 元每百万 tokens，音频输入/输出为 6/12 元每百万 tokens。估算不含输入转写、DeepSeek 或尚未返回的用量；前端时限不是账户费用硬上限，以控制台账单为准。

服务端接口：GET `/api/voice/config` 返回 `{ configured, model, maxSeconds: null }`，`null` 表示应用无时长上限；POST `/api/voice/session` 接受 `application/sdp`（最多 64 KiB），成功返回 SDP。错误统一为 `{ error: { code, message } }`，包括 400 无效 SDP、403 非本机同源、405 方法错误、413 请求过大、415 格式错误、429 频率受限、503 缺配置/权限、502 上游失败、504 超时。连接协商最多 20 秒，同一进程最多同时一个协商、每分钟 3 次，无自动重试。使用旧服务端时页面会提示更新并重启。

消息接口：POST `/api/voice/messages` 接受 `{ instructions }`，返回 `{ id, maxSeconds: null }`；POST `/api/voice/messages/:id/turns` 接受 `{ id, audio }`（base64、16 kHz 单声道 PCM16），返回用户转写、AI 文字及 24 kHz PCM 语音；DELETE `/api/voice/messages/:id` 释放会话。最多一个消息会话、每分钟 3 次连接，单轮串行，回复超时 45 秒；无应用总时长或总消息条数上限。同 ID 同录音返回当前/最近结果，不再次请求 AI；同 ID 不同录音拒绝。分享包自带 `ws` 运行时，真实 Key 不打包。

官方参考：[实时接入](https://help.aliyun.com/zh/model-studio/realtime)、[客户端事件](https://help.aliyun.com/zh/model-studio/client-events)、[模型计费](https://help.aliyun.com/zh/model-studio/model-pricing)。

配置接口：`PUT /api/voice/config` 接受 `{ apiKey, workspaceId }` JSON（最多 8 KiB，5 秒超时），`DELETE /api/voice/config` 清除配置；均限定本机同源，返回相同的无凭证状态对象。无效输入不会覆盖原配置；保存失败返回 500，不宣称保存成功。

启动时通过 `replaceTrack(null)` 暂停音频发送，收到 `session.created` 后发送会话配置并恢复轨道；收到 `session.updated` 前保持麦克风禁用。服务错误提示区分会话建立、会话配置和对话阶段，仅显示白名单中的错误类型、错误码和参数名，不显示服务端原始消息或凭证。

联调限制：取消回复遇到已结束响应时，仅对可明确识别的取消竞态保留连接；未识别的服务错误会结束对话。真实取消错误的消息格式、音频缓存和打断效果需要使用本机凭证验证，模拟测试不证明通话质量。

### 词库维护（V5.3）

生产 SoT：`data/vocabulary-packs/trusted_v5_2_vocabulary_pack.json` + `src/data/seedVocabulary.ts`。不要手改 `public/data/bundledSeed*.json`。

历史批次脚本（`seed:fix-p0` … `seed:fix-b8`、`seed:upgrade*` 等）已归档至 `scripts/archive/`，仅作追溯；日常维护只用 `seed:pack` / `seed:quality` / `seed:validate-sense`。总报告：`data/vocabulary-packs/v53-wrapup-report.md`。

种子词库以静态资源形式放在 `public/data/`，只在空库或 seedContentRevision 变化时按需加载，不进入 JS bundle。

多义增量包为 `public/data/bundledDictionarySenses.json`，按独立 `dictionaryContentRevision` 在启动时加载并合并。2026-10-11 已查询内置词条及本地工作词库的 7,532 个表达：7,039 个有词典结果，共 25,790 个来源义项；3,577 个表达返回多个义项。493 个未收录或词头变体保留原内容，详见 [覆盖报告](data/dictionary-senses/README.md)。新增义项默认暂停，原内容、分类、已会及学习进度保留，多标签页合并使用同一事务防止重复。

构建需要 Node.js 24：`npm run seed:senses`。逐条缓存到本地 `data/dictionary-senses/lookups.jsonl`（Git 忽略），可断点续跑；`npm run seed:senses -- --retry-unresolved` 复查异常结果。

时效性术语（SIBOR / OPIC / FHLBB / NAA）：**保留历史头词**，定义与中文标明历史地位及现行接替名称。

### macOS 桌面快捷方式

首次成功执行 `npm run dev` 后，会在桌面生成 `Recall English.command`：双击即可启动本地服务并打开网页；若服务已在运行则只打开网页。若需重新生成，删除项目根目录的 `.mac-desktop-shortcut` 后再启动一次。

## 项目结构（简要）

```
src/
  components/   # 今日学习、词库、添加、设置、学习会话
  data/         # 种子词（手写部分）、列表定义
  domain/       # 领域类型
  lib/          # DB、调度、词典、备份、发音、词包等
public/data/             # 打包词库 JSON（按需加载的静态资源）
data/vocabulary-packs/   # 词包源文件（需时 npm run seed:pack）
scripts/                 # 词包构建、质量闸、macOS 快捷方式等
```

开发服务器通过 Vite 代理访问 DeepSeek、Free Dictionary、有道，避免浏览器 CORS 限制。

## 学习与数据说明

- 首页与开始学习使用同一份 `DailyPlan`。每日新表达数量按设置固定，不因预计时间或回忆表现减少：先按优先列表顺序选词，剩余额度补充普通词，训练先完成优先新词再进行普通新词。可学词库不足时按现有数量安排。到期回忆、已解锁的应用及已引入表达未完成的方向仍先安排；时间不足可分次继续。
- 新词额度按每天首次引入的唯一义项计算，重试、另一方向、暂停词条或继续学习均不会绕过上限。
- 同词各义项继续独立排程和记录学习证据，归并展示不会合并掌握状态。英译中题提供目标义项的英语例句，缺例句时使用英文定义或搭配；题目语境不计为提示。多义词缺少以上英语资料时，暂不安排该义项的英译中题，补齐后恢复排程，中文到英文仍可训练。造句题明确本题义项，AI 验证只接受该义项的使用。常用程度尚未自动分级，首次查词默认勾选首个有中文的词义，训练选择由用户确认。
- 预计题量按回忆题 45 秒、应用题 120 秒组题；实际计时只记录前台、有焦点且可操作的学习和反馈时间，排除后台、暂停和阻塞等待。120 秒无操作会暂停；达到预算后完成当前题，再结束或主动继续 5 分钟。继续部分计入同一天，新词上限不变。
- 学习计时每 5 秒及暂停、退出时保存。跨午夜分别归入当地日期；异常关闭可能遗漏最后不足 5 秒，不推算离线时间。
- “表达数”“不同题数”“作答次数”分开：重试增加作答次数，不增加表达或不同题数。近 7 天延迟正确率要求距上次同方向练习至少 24 小时，排除首次学习、提示、自评、即时重试与未知结果；无提示主动揭晓记为失败。该指标用于展示记忆状态，不自动调整每日新词数量。
- “双向可回忆”要求两个方向均有无提示成功证据；“保持已验证”还要求各方向至少两次有效成功，后一次距离此前最近一次同方向练习至少 7 天，且都在最近明确失败之后。7 天是透明的产品门槛，不代表永久掌握。慢但正确不等于遗忘，到期和暂停也不抹除能力证据。
- 填空、自由造句分开验证。关键词或范句匹配不证明自由应用；AI 通过标明辅助来源，不推定其他场景的迁移能力。缺应用题不阻塞基础回忆阶段。
- 自定义词汇可先查词典缓存，只有加入「优先学习」或正式导入时才进入学习词表。
- **词库导出**：义项与分类归属；导入为合并，不覆盖学习进度。
- **学习备份 V3**：词条 + 进度 + 证据 + 时间账本 + 设置；导入会整库替换。继续支持 V1/V2 导入；旧版应用不支持新 V3 文件。
- **个人正文编辑**：新备份与词库文件可包含可选 `contentEdited` 布尔字段。当前应用继续接受没有该字段的旧文件；不支持此字段的旧应用可能拒绝新文件。词库编辑修正中文义项时，被替换的旧义项答案会移除，其他独立答案保留。
- **旧数据升级**：保留词条 ID、FSRS 与全部作答；旧 `coreMinutes` 迁入每日预算，`extensionMinutes` 不自动相加。旧作答缺乏可靠计时与来源，不回填时间或推定为已验证证据；因此新证据统计可能少于旧阶段统计，原有复习进度仍保留。
- 清除站点数据会删除本地进度与 API Key，请定期备份。

## 许可与隐私

本仓库默认按作者用途分发；API Key 与学习数据均留在本机，不会上传到本项目自身的服务器。使用第三方词典 / AI 服务时，查询内容会发往对应服务商，请自行遵守其条款。
## 词汇难度与已会

难度覆盖、已会标记和学习证据均按独立义项 Word.id 保存，而不是按英文拼写合并。例如 interest 的兴趣义与利息义可以分别设级、分别跳过。公开词表按词头/词性提供基础参考，界面明确标注「词头参考，义项可修正」。同词同词性的不同义项不会被宣称拥有已验证的同一等级；当前支持逐义项人工修正。未来模型分级需输入完整定义、中文义项及例句，按义项保存模型、来源和置信度，Jev 尚未接入。

学习设置提供 A1–C2 起始词级，默认 B1，可开关自动调整。词库显示词级、筛选难度和已会状态；编辑词条可手动修正等级。词级来自 [CEFR-J / Octanove](https://github.com/openlanguageprofiles/olp-en-cefrj)，未匹配的表达统一估算 B2 并明确标注。来源、许可和固定数据版本见 [data/word-levels/README.md](data/word-levels/README.md)。词级参考不代表用户水平或每个专业义项的难度，也不同于 FSRS 的记忆 difficulty 参数。

每日新词数量保持固定。优先学习先按列表顺序安排，不受词级设置影响，剩余额度补普通词。普通词先选择目标等级，同级不足再选相邻等级，并在同一难度范围内保留分类占比。普通新词每组最多三个，先完成这一组双向练习再进入下一组。

自动调整只使用保存的普通新词首次练习证据：一个词双向首轮、无提示、未覆写、经规则或 AI 验证准确答对，理解方向不超过 12 秒、表达方向不超过 15 秒，计一次轻松；连续三个轻松词升一级。首轮明确答错、想不起来，或依赖二级以上提示才答对，计一次困难；连续两个困难词降一级。每词最多计算一次，重试、旧词复习、未验证、优先词不参与。上下限 A1/C2。阈值是产品规则，未经过水平测评校准。

调整立即替换会话中尚未开始的普通新词，保留已经开始的方向、复习和重试，不重置计时。已会可从词库或训练标记，跳过新学及复习，撤销后恢复原进度；不制造掌握证据，不删除历史。训练中未开始的已会词会补位，已产生学习记录的词保留当日引入计数。备份保留已会、词级覆盖、难度设置及作答元数据；词库导出不含个人已会状态。修改起始等级或自动调整开关后重新累计。
