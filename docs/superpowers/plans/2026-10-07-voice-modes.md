# 口语双模式实施计划

目标：提供「实时畅聊／语音消息」入口、真实麦克风音量反馈和可回听的录音消息。

约束：保留已有 WebRTC 启动修复；继续使用北京千问与本机凭证；录音只在页面内存中；单条 1—60 秒、会话 5 分钟；无自动重试；既有场景、词汇和 DeepSeek 反馈共用。

- [x] 音频工具：Web Audio 音量监听、16 kHz PCM 录制与 WAV 回听，停止/取消/迟到权限完整释放。
- [x] 本机消息接口：POST `/api/voice/messages` 建立 Manual 会话，POST `/:id/turns` 提交 PCM，DELETE `/:id` 结束；同源校验、大小/时长限制、单轮串行、消息 ID 去重、超时及断线释放。
- [x] 前端：模式卡、实时音量条、按住录制/上滑取消和点击录制、语音条回放与转写、错误保留录音、课后反馈。
- [x] 集成：Vite/preview/分享服务共用接口和凭证，分享包包含 ws；文档说明录音生命周期。
- [x] 验证：先写失败用例，完成相关测试、构建、lint、真实浏览器桌面/手机 UI 验证；浏览器检查不保留模拟视口。

验证记录（2026-10-07）：`npm test` 42 文件 / 269 用例通过；`npm run build` 通过（主 bundle >500 kB 警告）；`npm run lint` 成功退出，仍有 warning；`git diff --check` 无错误。只读审查发现并修复停止录音时的取消竞态，有先失败后通过的回归测试。

Tabbit 中用本地合成音频和模拟回复验证了真实 AudioWorklet 录制、音量变化、取消不发送、松开发送、有效 WAV 回听和结束后轨道停止；生产构建中内联 worklet 也可加载。修复了 StrictMode 清理移除 audio src 的回放问题并增加回归测试。390×844 窄屏 DOM 尺寸验证无横向溢出，底部说明不被导航覆盖；专用窄屏标签已关闭，展示页面恢复原生 1424×763 视口并释放浏览器任务。截图服务超时，未完成像素截图检查。

隔离目录中的分享服务能携带 ws 启动，GET 配置返回未配置、POST 消息返回 503；测试服务已停止。没有覆盖 Downloads 分享包，没有读取真实凭证，也没有请求真实百炼或 DeepSeek 服务；新消息模式的模型权限、识别与实际回复质量仍需真实使用验证。
