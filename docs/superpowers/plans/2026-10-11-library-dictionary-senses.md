# 全库多义配置实施计划

> 使用 executing-plans 按任务逐项实施；用户已授权全库查询和配置。

**Goal:** 为目前 7,496 个词条查询并配置来源词典返回的全部中文义项。

**Architecture:** 复用现有 Youdao 解析器，批量查询生成静态增量包；浏览器启动时按独立版本增量合并，复用单词补全的义项匹配规则。新增义项默认暂停，不覆盖任何旧词、用户编辑或学习记录。

**Tech Stack:** Node.js 24、TypeScript、React、IndexedDB、Vitest。

## 约束

- 查询结果逐条落盘，有限并发，临时失败重试；中断可续跑。
- 词典未收录、不同词头、真正单义词如实记录，不伪造多义。
- 不提高原始 seed 版本，不触发旧 seed 内容重写；不改变数据库或备份版本。
- 不提交、不发布，不重置浏览器数据。
