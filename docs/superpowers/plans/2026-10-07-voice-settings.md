# 口语凭证设置实施计划

用户要求在学习设置中直接输入口语陪练 Key，沿用 DeepSeek 区域的输入风格。保留服务端持有千问凭证的架构。

1. 服务端 `PUT/DELETE /api/voice/config`：本机同源校验，受限 JSON 请求，校验 Key 和北京业务空间 ID；原子保存至 `.env.voice.local.json`，清除时禁用已保存配置及环境变量回退，不修改 `.env.local`。该文件名及临时文件匹配 Vite 默认拒绝访问和 Git 排除的 `.env.*`。读取接口只返回状态，不返回凭证。测试即时生效、重启恢复、错误不覆盖、清除、跨域和存储失败。
2. `VoiceServiceStatus.tsx`：密码输入框、业务空间输入框、保存和清除按钮；显示提交中与成功/失败，成功后清空输入并刷新状态，不存入浏览器或备份。测试保存、清除、失败和卸载取消。
3. Vite 与分享服务器指定本机凭证路径；Git 排除该文件及临时文件，分享包仅复制原有白名单文件。更新 README，执行相关测试、整库测试、build、lint 及浏览器检查。
