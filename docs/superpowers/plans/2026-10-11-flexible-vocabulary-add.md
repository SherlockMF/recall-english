# 自动归类与多格式添加

沿用现有词典缓存、义项保存与 IndexedDB，不新增依赖或模型接口。默认逐义项自动判断日常、商务、金融、会计，用户明确指定分类时优先使用该分类。已有义项的个人分类、已会与进度不被重复导入覆盖。

- [x] 增加独立粘贴解析器：纯英文、Tab、CSV、竖线、英文后接中文，支持表头及可选词性、分类列；无效行逐条提示。
- [x] 补全导入：查询现有词典并保存来源返回的全部义项；纯英文默认训练首个双语义项，指定中文时仅训练对应义项。缺中文仅保存暂停义项；网络失败时保留失败行，已有中文可本地保存并提示补全失败。
- [x] 添加页默认自动分类，单条纯英文可直接保存；显示批量进度、部分失败、可复制格式说明和示例。
- [x] 整理共享充电宝商业化专用词库，提供明确义项、分类、定义、工作例句及可导入文件；通过当前用户词库入口加入 42 个新义项。
- [x] 运行解析器、分类、义项保存、添加交互测试，再运行完整测试、build、lint；检查实际添加页面。

主要文件：src/lib/vocabularyImport.ts、inferCategory.ts、wordSenses.ts；src/components/AddView.tsx、src/App.tsx、src/styles.css；对应测试、README 与共享充电宝词库文件。

格式约定：无表头时列顺序为英文、中文、词性、分类；有表头可调整顺序，支持 expression/word/英文、zhGloss/meaning/中文、partOfSpeech/pos/词性、category/分类。分类可写 daily/日常生活、business/商务英语、finance/金融英语、accounting/会计英语。英文短语中的空格保留；含分隔符的 CSV 字段需用双引号。
